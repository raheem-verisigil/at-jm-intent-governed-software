Prototype boundaries

Built to be inspectable. Honest about its limits.

INPUTS

Deterministic evaluation

Supported fields and enumerated values make the prototype's policy path inspectable.

EVIDENCE

Uncertainty stays visible

Missing or contradictory evidence does not produce an allow decision in this prototype.

AUTHORITY

Human review remains explicit

Sensitive actions can return approval-required; the API does not authenticate reviewers or enforce decisions in external systems.

Prototype v0.1 is not security-audited. It does not execute code, authenticate users or approvals, verify evidence provenance, persist an evidence ledger, or control production systems. An ALLOW response is not authorization to execute an action in a real environment.
